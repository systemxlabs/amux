# 产品需求文档

## 需求背景

Agent 更适合交由模型厂商来做，模型厂商可对自家模型和 harness 协同优化以最大化智能体能力。

用户通常会使用多种模型，例如简单任务交由 DeepSeek 模型来做，复杂编码任务交由 OpenAI 模型来做，同一任务内也可能使用多种模型交叉验证。

用户通常会在不同机器上使用 agent，例如个人电脑和公司服务器，一个任务可能会跨不同机器（例如本地修改代码，服务器编译和测试）。

所以需要有一个可跨多机器多 agent，且支持工作流方式运行复杂任务的产品。

## 产品理念

- 将 agent 交由模型厂商实现，在 agent 之上构建支持多机器多 agent 的个人开发环境
- 支持单 agent 单会话模式，用于快速发起简单任务
- 支持多 agent 工作流模式，用于执行固定模式的复杂任务
  - 使用自然语言描述工作流计划，由智能体来驱动工作流
  - 使用单 agent 单会话来执行子任务
  - 用户可随时介入工作流和子任务执行
- 支持多 agent 群聊模式，用于执行非固定模式的复杂任务
  - 给群聊内每个 agent 定义角色，使用单会话模式来驱动该角色执行
  - 基于 @ 的方式驱动
- 参考 tmux 将 agent 执行与应用解耦，应用关闭不影响 agent 执行，多个应用可同时连接并访问同一会话

## 功能说明

### 普通会话

普通会话是用户直接与某一机器某一 agent 的直接对话，用户可指定 agent 执行目录，可干预或取消 agent 执行，可查看 agent 行为和输出，agent 执行运行在对应机器后台。

普通会话包含
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中
- 执行目录：会话实际执行目录，可为指定工作目录或其 worktree 目录
- 对话历史：用户和 agent 之间的对话历史
- 活动历史：agent 活动历史，包括思考、工具执行、执行错误等
- 会话选项：可用于调整 agent 会话的选项，如模型、推理级别
- 斜杠命令：可用于调用 agent 特别的能力，如 `/goal`
- 会话计划：agent 如何完成用户复杂指令的计划
- 会话用量：模型上下文使用量

应用关闭不影响 agent 执行，重新打开应用后恢复普通会话的对话历史、活动历史和当前状态等。

多应用可连接查看并操作同一普通会话。

#### 最近工作目录

产品应记住不同机器最近使用的工作目录，在创建普通会话时用户可快速选择最近工作目录。

### 工作流会话

工作流会话是用户与产品内置工作流智能体的对话，工作流智能体基于工作流计划和用户任务指令，通过发起普通会话来调度不同机器不同 agent 运行。

工作流会话包含
- 计划：自然语言描述工作流如何执行
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中（工作流智能体调度中或关联普通会话正在工作中）
- 对话历史：用户和工作流智能体之间的对话历史
- 活动历史：工作流智能体活动历史，包括思考、工具执行、执行错误等
- 关联普通会话：工作流智能体发起的普通会话

工作流会话取消采用系统注入用户角色消息的方式，由工作流智能体向关联普通会话发送取消指令。

用户删除工作流会话时，删除工作流会话和其关联的所有普通会话。

应用关闭不影响工作流会话，重新打开应用后恢复工作流会话的对话历史和活动历史和当前状态。

多应用可连接查看并操作同一工作流会话。

#### 工作流智能体

工作流智能体负责按工作流计划进行调度，传递用户指令和关联普通会话内容，不进行任务拆解、任务执行和任务决策，工作流智能体可执行工作流计划中明确写出的条件分支（如「审查不通过则打回修改」），但不创造计划之外的步骤、不自主变更目标，未在工作流计划和用户指令中指定的事项交由用户决定。

#### 工作流驱动

工作流智能体在调度动作结束后进入空闲状态，当关联普通会话状态从工作中变为空闲且非取消原因时，系统自动以用户消息向工作流会话注入一段提示词，触发工作流智能体进入工作状态，进行下一阶段调度。

用户可随时向工作流会话输入指令来调整工作流调度、恢复已取消或执行异常的工作流。

需要人类判断时（如通知人类审查），工作流智能体在工作流会话输出结论并回到空闲状态等待，用户审查完毕后，向工作流会话输入指令来继续推进工作流。

#### 工作流计划

工作流计划通过自然语言描述，支持指定机器和 agent，支持指定工作目录，支持使用 worktree 方式，支持编码-审查循环，支持人类审查等等。以下是一段示例

> 使用 xxx 远程机器的 codex 实现功能并提交推送分支，然后使用本机的 claude code 拉取代码并审查，并将审查意见给到 xxx 远程机器的 codex 进行修改，直至审查通过，然后通知人类审查。人类审查通过后，最终由本机 kimi code 操控浏览器创建 PR

用户可提前保存工作流计划，可用于快速发起工作流会话。

### 群聊会话

群聊会话是用户与多个 agent 之间的对话，每个群聊成员可以看到整个群聊消息，可以发送消息 @ 其他成员。群聊会话中每个 agent 成员背后对应一个成员普通会话，系统会在群聊消息 @ 提及 agent 成员时，通过向对应成员普通会话以用户角色发送消息来驱动 agent 运行。

群聊会话包含
- 成员：包括用户和多个 agent
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中（任一成员普通会话正在工作中）
- 对话历史：用户和多个 agent 之间的对话历史
- 成员普通会话：群聊成员背后的普通会话

### 项目管理

项目是一个逻辑概念，主要用于将会话分组聚合展示。不同机器上的目录、同一机器上的不同目录都可以归属一个项目。

项目删除后，其下会话回到未归属。项目名称不支持修改。

### 改动审查

用户可在应用内部查看当前普通会话的文件改动，并进行审查
- 支持以文件树方式浏览改动文件
- 支持 inline 方式查看文件改动
- 支持切换对比的基准分支
- 支持对文件或代码块进行评论，评论以用户消息进入会话对话
  - 文件评论：`<文件路径> <评论内容>`
  - 代码块评论
    > ```
    > <选中代码块>（包括 +/- 前缀）
    > ```
    > <评论内容>

### 执行目录浏览

用户可在应用内部浏览当前普通会话执行目录
- 支持以文件树方式浏览目录
- 支持查看文本文件内容

### 技能管理

集中管理用户常用技能，可对不同机器的不同 agent 安装、更新或卸载指定技能。
- 技能格式：包括名称和一段提示词（可以是仓库 / 资源 URL，也可以是下载与安装的方法说明）
- 技能安装、更新或卸载：通过创建一个普通会话，工作目录为系统临时目录，系统拼接提示词作为用户消息往该会话发送，由 agent 根据提示词进行安装、更新或卸载，用户可随时进入该会话干预调整

### 快捷指令

快捷指令是提前保存的一段常用提示词，用于快速发送而无需用户打字或说话。快捷指令分项目快捷指令和通用快捷指令，项目快捷指令与特定项目绑定，而通用快捷指令不与任何项目绑定。
- 指令格式：包括名称和一段提示词
- 指令使用：通过 UI 按钮点击，往普通或工作流会话中发送提前保存的提示词作为用户输入

项目删除时，连带删除与该项目绑定的快捷指令。

### 机器管理

用户可在产品内进行机器和 agent 管理
- 查看机器列表
- 机器操作：重新发现 agents
- 查看机器上 agent 列表
- agent 操作：重启

### 自动化

用户可定时或利用 webhook 来自动化执行任务。自动化包括
- 任务内容：一段提示词
- 触发：定时或 Github Webhook
- 会话选项：可选择已有会话或新建会话来执行任务
- 运行结果：可设定结果分类，由决策模型打标

## 应用 UI 设计

### 登录页面

应用打开后，正在建立连接过程中，整个页面展示转圈。

应用打开后，当无法成功连接 Server 时，则会进入登录页面，其内容居中展示
- 错误提示：当连接失败时，展示错误信息。若本地无连接信息则不展示
- 认证 token 输入框
- 进入按钮：点击并连接成功后进入主页面

应用使用过程中，如果任何请求返回未认证响应，立即跳转至登录页面。

### 主页面

应用主页面布局采用左、中、右三块面板，面板宽度均可拖拽，不限制最大宽度，最小宽度以保证可拖拽回为准。

左侧面板包含
- 功能列表视图：包含新建会话、自动化
- 会话列表视图
- 设置入口：位于左侧面板左下角，点击打开设置浮窗

中间面板包括
- 新建会话视图
- 会话交互视图

右侧面板默认折叠，需要点击中间面板悬浮按钮才能展开
- 执行目录（仅普通会话展示）
- 改动审查（仅普通会话展示）
- 会话详情：会话元信息
- 会话活动（仅普通会话和工作流会话展示）
- 会话计划（仅普通会话展示）：展示 agent 计划，若无则展示“暂无会话计划”
- 终端（仅普通会话展示）：可创建多个终端，可关闭终端，可执行 shell 命令并查看输出
- 附件：展示附件列表，可滚动查看更多，可删除指定附件，可删除所有附件

#### 会话列表视图

会话列表视图位于左侧面板，包含新建会话入口、会话列表
- 顶部栏
  - “会话列表”标题：左对齐
  - 新建会话按钮：采用「+」，右对齐，点击进入新建会话视图
- 会话按项目分组展示：普通会话与工作流会话统一归入其所属项目组，未归属项目的会话在列表末端展示
- 项目组
  - 组头：折叠展开提示 + 分组名（项目名 + 「·」+ 项目描述），分组名宽度自适应 + 超长截断
  - 默认展开，左键点击折叠展开该组，折叠时不加载组内会话，展开时才加载组内会话
  - 组间按项目顺序排序
- 组内会话
  - 所有置顶会话放在最前面，按创建时间排序
  - 非置顶会话统一按创建时间排序
  - 默认仅展示首页 5 条会话，组尾整行「显示更多」加载该组更老的一页
- 未归属项目会话
  - 没有组头，通过分隔线跟项目组分隔
  - 所有置顶会话放在最前面，按创建时间排序
  - 非置顶会话统一按创建时间排序
  - 默认展示前 20 条会话，可滚动加载更多页进行查看
- 普通会话项：包含「终端」图标、「别针」图标（如置顶）、标题和会话状态，标题宽度自适应 + 超长截断，会话状态右对齐
- 工作流会话项
  - 包含「网络」图标、「别针」图标（如置顶）、标题、折叠展开提示按钮和会话状态，折叠展开提示按钮和会话状态右对齐，标题宽度自适应 + 超长截断
  - 挂载若干关联普通会话，默认折叠，可展开查看；展开后置顶的关联普通会话放在最前面，其余按其自身创建时间排序（不影响工作流会话在列表中的位置）
  - 使用树形连接线表示工作流会话与关联普通会话的从属关系
  - 关联普通会话项：缩进，其他和普通会话一样
- 群聊会话项
  - 包含「群聊」图标、「别针」图标（如置顶）、标题、折叠展开提示按钮和会话状态，折叠展开提示按钮和会话状态右对齐，标题宽度自适应 + 超长截断
  - 挂载若干成员普通会话，默认折叠，可展开查看；展开后置顶的成员普通会话放在最前面，其余按其自身创建时间排序（不影响群聊会话在列表中的位置）
  - 使用树形连接线表示群聊会话与成员普通会话的从属关系
  - 成员普通会话项：缩进，其他和普通会话一样
- 会话状态：使用转圈表示工作中，空闲则不展示
- 会话列表默认仅展示首页会话，滚动至底部或顶部时自动加载下一页或上一页
- 右键点击会话列表项弹出菜单
  - 重命名：行内修改标题，按 Enter 保存，按 ESC 或输入框失焦则取消
  - 新建会话（仅限普通会话、工作流会话和群聊会话）：以相同设置快速新建一个会话，并切换到该会话
  - 置顶/取消置顶
  - 删除：弹窗确认
- 左键点击会话列表项，中间面板进入会话交互视图
- 左键可拖动会话，切换项目组，或将其项目置为未归属

#### 新建会话视图

新建会话视图位于中间面板，居中展示
- 顶部为模式切换：普通 / 工作流 / 群聊
- 若无连接机器，整个视图居中展示提示“请运行 amux-daemon 程序将机器连接至服务器”
- 普通模式
  - 机器：采用选项按钮组
  - 智能体：采用选项按钮组
    - 若未选中机器，展示“请选择机器”
    - 若选中机器，展示机器上发现的 agents，不可用的 agent 置灰不可点击
  - 工作目录输入框：输入框点击后，弹出上拉框展示从最近工作目录中选择，用户手动输入时，取消上拉框，自动弹出下拉框展示前缀匹配的目录项可供选择，当输入框失焦后取消上下拉框
    - 最近工作目录项删除按钮「x」：右对齐，点击删除该项
  - 项目：采用选项按钮组，未选择即未归属，点击当前已选项目时取消选择，根据最近工作目录预选项目
  - worktree 开关和基分支可搜索下拉框：基分支优先 origin 的远程仓库默认分支，不存在时使用其他远程仓库默认分支，均不存在则为空；本地分支展示为 `本地 <branch>`，远程跟踪分支展示为 `远程 <remote>/<branch>`
  - 创建会话按钮：默认置灰不可点击，当已选择机器、已选择可用 agent、工作目录非空且若开启 worktree 需基分支不为空后才可点击
- 工作流模式
  - 若工作流智能体未配置，则报错并引导用户进入设置页面-工作流设置
  - 若工作流智能体已配置，则视图为
    - 工作流计划输入框：用户直接输入，也可从上拉框中选择提前保存的计划
    - 项目：采用选项按钮组，未选择即未归属，点击当前已选项目时取消选择，根据工作流计划预选项目
    - 创建会话按钮：默认置灰不可点击，当工作流计划已输入或已选择后才可点击
- 群聊模式
  - 群聊成员设置：可从群聊模板中选择，也可自行配置
  - 项目：采用选项按钮组，未选择即未归属，点击当前已选项目时取消选择
  - 创建会话按钮：默认置灰不可点击，当群聊成员已设置后才可点击
- 点击创建会话按钮后，跳转至会话交互视图

进入新建会话视图时，收起右侧面板。新建会话视图应记住当前所选模式，以及表单输入内容，创建会话成功后清空表单。

#### 会话交互视图

会话交互视图位于中间面板。

普通会话和工作流会话交互视图
- 顶部栏：左上方标注
  - 智能体名称（`<agent>@<machine>` 或工作流智能体）
  - 智能体状态：可用性圆点 + 状态名称
  - 执行目录和 Git 分支（普通会话）：若执行目录不是 Git 仓库则不展示分支
  - 工作流计划（工作流会话）：过长则截断展示，悬浮时 tooltip 展示全部
- 对话历史
  - 类似 IM 应用展示用户消息与智能体输出的消息气泡，消息气泡包含时间和消息内容，消息内容按 markdown 格式进行渲染
  - 可滚动查看对话历史，滚动至底部或顶部时自动加载下一页或上一页
  - 进入时自动滚动到最底部，且在底部时新消息保持跟随滚动
- 实时活动——展示正在进行的活动（如无则不展示），活动内容格式参考会话活动视图，宽度自适应 + 超长省略
- 快捷指令栏——以分隔符分组展示快捷指令按钮，先展示项目快捷指令（若会话归属某项目），再展示通用快捷指令，鼠标悬浮时以 tooltip 展示指令内容
- 附件栏——上传中附件以转圈展示，可取消并移除；已上传附件可被移除；上传失败的附件标示失败，可重试或移除
- 输入区
  - 多行输入框，可拖拽高度，Enter 发送，Shift + Enter 换行
  - 可拖拽文件和图片，可粘贴图片
  - 输入 `/` 时根据前缀匹配斜杠命令，弹出上拉框供用户选择
  - 输入框内底部
    - 附件按钮：左对齐，点击弹出文件选择窗口
    - 会话用量、发送和取消按钮：右对齐；会话用量使用圆圈百分比展示，悬浮时以 tooltip 展示精确数值，若无会话用量数据则不展示
