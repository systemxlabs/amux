# 产品需求文档

## 需求背景

agent 更适合交由模型厂商来做，模型厂商可根据自身模型来优化 harness 以最大化发挥模型能力。

用户通常会使用多种模型，例如简单任务交由 DeepSeek 模型来做，复杂编码任务交由 OpenAI 模型来做，同一任务内也可能使用多种模型交叉验证。

用户通常会在不同机器上使用 agent，例如个人电脑和公司服务器，一个任务可能会跨不同机器（例如本地修改代码，服务器编译和测试）。

所以需要有一个可跨多机器多 agent，且支持工作流方式运行复杂任务的产品。

## 产品理念

- 将 agent 交由模型厂商实现，在 agent 之上构建面向多机器多 agent 的工作流编排系统
- 使用自然语言描述工作流计划，由智能体来驱动工作流
- 参考 tmux 将 agent 执行与应用解耦，应用关闭不影响 agent 执行，多个应用（例如桌面应用和移动端应用）可同时连接并访问同一会话

## 功能说明

### 普通会话

普通会话是用户直接与某一机器某一 agent 的直接对话，用户可指定 agent 工作目录，可干预或取消 agent 执行，可查看 agent 行为和输出，agent 执行运行在对应机器后台。

普通会话包含
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中
- 工作目录：用户指定目录，支持 git worktree
- 对话历史：类似 IM 应用的用户和 agent 之间的对话历史
- 活动历史：agent 活动历史，包括思考、工具执行、执行错误等
- 会话选项：可用于调整 agent 会话的选项，如模型、推理级别
- 斜杠命令：可用于调用 agent 特别的能力，如 `/goal`

应用关闭不影响 agent 执行，重新打开应用后恢复普通会话的对话历史、活动历史和当前状态等。

多应用可连接查看并操作同一普通会话。

#### 常用工作目录

应用侧应记住不同机器最近使用的工作目录，在创建普通会话时用户可快速选择常用工作目录。

### 工作流会话

工作流会话是用户与应用内置编排智能体的对话，编排智能体基于工作流计划和用户任务指令，通过发起普通会话来调度不同机器不同 agent 运行。

工作流会话包含
- 计划：自然语言描述工作流如何执行
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中（编排智能体调度中或关联普通会话正在工作中）
- 对话历史：类似 IM 应用的用户和编排智能体之间的对话历史
- 活动历史：编排智能体活动历史，包括思考、工具执行、执行错误等
- 关联普通会话：编排智能体发起的普通会话

工作流会话取消采用用户消息的方式，由编排智能体向关联普通会话发送取消指令。

用户删除工作流会话时，删除工作流会话和其关联的所有普通会话。

应用关闭时工作流会话停止，关联普通会话不受影响，重新打开应用后可以看到工作流会话的对话历史和活动历史，此时状态为空闲，如需重新启动工作流，需用户手动触发。

工作流会话只有其所属应用可查看和操作，其他应用无法查看，工作流会话关联的普通会话可被其他应用查看和操作。

#### 编排智能体

编排智能体负责按工作流计划进行调度，传递用户指令和关联普通会话内容，不进行任务拆解、任务执行和任务决策，编排智能体可执行工作流计划中明确写出的条件分支（如「审查不通过则打回修改」），但不创造计划之外的步骤、不自主变更目标，未在工作流计划和用户指令中指定的事项交由用户决定。

编排智能体执行运行在应用侧，应用关闭则编排智能体停止执行。

#### 工作流驱动

编排智能体在调度动作结束后进入空闲状态，当关联普通会话状态从工作中变为空闲时，系统自动以用户消息向工作流会话注入一段提示词，触发编排智能体进入工作状态，进行下一阶段调度。

用户可随时向工作流会话输入指令来调整工作流调度、恢复已取消或执行异常的工作流。

需要人类判断时（如通知人类审查），编排智能体在工作流会话输出结论并回到空闲状态等待，用户审查完毕后，向工作流会话输入指令来继续推进工作流。

#### 工作流计划

工作流计划通过自然语言描述，支持指定机器和 agent，支持指定工作目录，支持使用 worktree 方式，支持编码-审查循环，支持人类审查等等。以下是一段示例

> 使用 xxx 远程机器的 codex 实现功能并提交推送分支，然后使用本机的 claude code 拉取代码并审查，并将审查意见给到 xxx 远程机器的 codex 进行修改，直至审查通过，然后通知人类审查。人类审查通过后，最终由本机 kimi code 操控浏览器创建 PR

用户可提前保存工作流计划，可用于快速发起工作流会话。

### 改动审查

用户可在应用内部查看当前普通会话的文件改动，并进行审查
- 支持以文件树方式浏览改动文件
- 支持 inline 方式查看文件改动
- 支持文件和代码块级别撤销操作
- 支持选择文件和代码块，向 agent 发送指令

### 工作目录浏览

用户可在应用内部浏览当前普通会话工作目录
- 支持以文件树方式浏览目录
- 支持查看文本文件内容

### 技能管理

集中管理用户常用技能，可对不同机器的不同 agent 安装、更新或卸载指定技能。
- 技能格式：包括名称和一段提示词（可以是仓库 / 资源 URL，也可以是下载与安装的方法说明）
- 技能安装、更新或卸载：通过创建一个普通会话，工作目录为系统临时目录，系统拼接提示词作为用户消息往该会话发送，由 agent 根据提示词进行安装、更新或卸载，用户可随时进入该会话干预调整

### 快捷指令

快捷指令是提前保存的一段常用提示词，用于快速发送而无需用户打字或说话。
- 指令格式：包括名称和一段提示词
- 指令使用：通过 UI 按钮点击，往普通或工作流会话中发送提前保存的提示词作为用户输入

### 机器管理

用户可在应用侧管理机器的注册和移除，可查看机器是否在线。

支持机器上的 agent 管理
- 查看机器上 agent 列表
- 查看 agent 可用状态
- 查看 agent 已安装的技能列表
- 可手动触发 agent 重启

## 桌面 GUI 设计

### 主页面

主页面布局由左、中、右三块面板组成。

#### 左侧面板

左侧面板包含新建会话、会话列表和设置入口
- 顶部「+」按钮进入新建会话视图
- 会话列表包含普通会话与工作流会话，统一按最近活跃排序，可向下滚动查看
- 工作流会话挂载若干关联普通会话，默认折叠，可展开查看；展开后关联普通会话按其自身最近活跃排序（不影响工作流会话在列表中的位置）
- 每条显示会话标题和会话状态，状态通过转圈（右对齐）表示工作中
- 右键点击会话弹出操作菜单：删除（弹窗确认）与重命名（行内修改标题）
- 底部为设置入口，点击打开设置浮窗

会话列表默认仅展示首页会话，可点击“加载更多”增加页数（+1），可点击“收起”使页数归 1。

#### 中间面板

中间面板包括新建会话视图和选中已有会话交互视图。

新建会话视图
- 顶部为模式切换：普通 / 工作流
- 普通模式
  - 若无机器已注册，则报错并引导用户进入设置页面-机器管理设置
  - 若有机器已注册，用户可选择机器与 agent（并列一排）、工作目录支持手动输入或从最近目录中选择，worktree 开关，创建会话按钮
- 工作流模式
  - 若编排智能体未配置，则报错并引导用户进入设置页面-编排智能体设置
  - 若编排智能体已配置，用户可选择提前保存的计划或直接输入计划，创建会话按钮
- 点击创建会话按钮后，跳转至会话交互视图

会话交互视图
- agent 名称和可用状态：左上方标注 agent 名称（`agent@机器` 或编排智能体）和 agent 可用状态
- 对话历史——类似 IM 应用展示用户消息与 agent 输出的消息气泡，消息气泡包含时间和消息内容，可向上滚动查看对话历史
- 实时活动——展示正在进行的活动（如无则不展示），一行展示，内容过长则截断
- 快捷按钮栏——展示用户设定的快捷按钮栏
- 输入区
  - 包含多行输入框，Enter 发送，Shift + Enter 换行
  - 可拖拽文件和图片，可粘贴图片
  - 输入 `/` 时根据前缀匹配斜杠命令，弹出上拉框供用户选择
  - 输入框右侧为发送和取消按钮
- 会话选项——位于输入框下方，根据选项类型使用下拉框、开关等组件
- 悬浮按钮——位于右侧边缘竖向排列，点击展开对应的右侧面板

#### 右侧面板

右侧面板默认折叠，可拖拽调整面板宽度，需要点击中间面板悬浮按钮才能展开
- 工作目录：按文件树浏览工作目录文件列表和文件内容
- 文件改动：查看文件改动和审查操作
- 会话详情：会话元信息（包含所属机器与 agent、工作目录、创建时间等尽可能多的信息）
- 会话活动：展示会话活动历史，可向上滚动查看，活动条目默认折叠简洁展示一行、可展开查看详情

文件改动审查视图
- 顶部为工具栏，包括折叠文件树和折叠文件改动按钮
- 左侧为文件树区域，仅包含改动文件列表，整个区域可展开/折叠
  - 按文件所在父目录路径分组展示，分组默认展开，分组可单独展开/折叠
  - 点击文件时，右侧自动滚动到对应 diff 区域
- 右侧以 inline 模式查看文件改动，可折叠全部 diff 仅显示文件名

### 设置页面

设置页面经主页面左侧面板底部的设置入口打开浮窗，浮窗以半透明遮罩盖在主界面之上，内部为**分类导航侧边栏 + 右侧设置内容**（类似系统设置），点遮罩或关闭按钮收起。

#### 机器管理设置

布局采用纵向堆叠的卡片式，每台机器一张卡片，卡片内有：
- 机器头：名称 + 机器状态徽章 + 「移除」按钮 + 「重连」按钮
- URL（单行，过长截断）
- 每个 agent 一行：agent 名称，agent 状态（可用/不可用），重启按钮

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。

机器移除按钮、机器重连按钮和 agent 重启按钮点击后需弹窗确认。

#### 编排智能体设置

配置大模型供应商连接，布局包括
- API 格式单选框：chat_completions / responses / messages
- Base URL 输入框
- API Key 输入框
- 模型名称输入框
- 保存按钮

#### 快捷指令设置

布局采用纵向堆叠的卡片式，每个指令一张卡片，卡片内有：
- 指令名称
- 指令内容，过长则截断展示
- 编辑按钮，点击后弹窗表单输入框
- 删除按钮，点击后弹窗确认

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。

#### 技能管理设置

布局采用纵向堆叠的卡片式，每个技能一张卡片，卡片内有：
- 技能名称
- 技能描述，过长则截断展示
- 安装/更新/卸载三个按钮，点击后弹窗，可选择指定机器和指定 agent
- 编辑按钮，点击后弹窗表单输入框
- 删除按钮，点击后弹窗确认

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。

#### 工作流计划设置

布局采用纵向堆叠的卡片式，每个计划一张卡片，卡片内有：
- 计划名称
- 计划内容，过长则截断展示
- 编辑按钮，点击后弹窗表单输入框
- 删除按钮，点击后弹窗确认

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。
