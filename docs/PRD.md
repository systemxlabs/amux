# 产品需求文档

## 需求背景

Agent 更适合交由模型厂商来做，模型厂商可对自家模型和 harness 协同优化以最大化智能体能力。

用户通常会使用多种模型，例如简单任务交由 DeepSeek 模型来做，复杂编码任务交由 OpenAI 模型来做，同一任务内也可能使用多种模型交叉验证。

用户通常会在不同机器上使用 agent，例如个人电脑和公司服务器，一个任务可能会跨不同机器（例如本地修改代码，服务器编译和测试）。

所以需要有一个可跨多机器多 agent，且支持工作流方式运行复杂任务的产品。

## 产品理念

- 将 agent 交由模型厂商实现，在 agent 之上构建面向多机器多 agent 的工作流编排系统
- 使用自然语言描述工作流计划，由智能体来驱动工作流
- 参考 tmux 将 agent 执行与应用解耦，应用关闭不影响 agent 执行，多个应用（例如桌面应用和移动端应用）可同时连接并访问同一会话

## 功能说明

### 普通会话

普通会话是用户直接与某一机器某一 agent 的直接对话，用户可指定 agent 工作目录，可干预或取消 agent 执行，可查看 agent 行为和输出，agent 执行运行在对应机器后台。

普通会话包含
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中
- 工作目录：用户指定目录，支持 git worktree
- 对话历史：用户和 agent 之间的对话历史
- 活动历史：agent 活动历史，包括思考、工具执行、执行错误等
- 会话选项：可用于调整 agent 会话的选项，如模型、推理级别
- 斜杠命令：可用于调用 agent 特别的能力，如 `/goal`
- 会话计划：agent 如何完成用户复杂指令的计划

应用关闭不影响 agent 执行，重新打开应用后恢复普通会话的对话历史、活动历史和当前状态等。

多应用可连接查看并操作同一普通会话。

#### 常用工作目录

产品应记住不同机器最近使用的工作目录，在创建普通会话时用户可快速选择常用工作目录。

### 工作流会话

工作流会话是用户与产品内置工作流智能体的对话，工作流智能体基于工作流计划和用户任务指令，通过发起普通会话来调度不同机器不同 agent 运行。

工作流会话包含
- 计划：自然语言描述工作流如何执行
- 会话标题：可由用户首个提示词生成，用户可更改
- 会话状态：空闲或者工作中（工作流智能体调度中或关联普通会话正在工作中）
- 对话历史：用户和工作流智能体之间的对话历史
- 活动历史：工作流智能体活动历史，包括思考、工具执行、执行错误等
- 关联普通会话：工作流智能体发起的普通会话

工作流会话取消采用系统注入用户角色消息的方式，由工作流智能体向关联普通会话发送取消指令。

用户删除工作流会话时，删除工作流会话和其关联的所有普通会话。

应用关闭不影响工作流会话，重新打开应用后恢复工作流会话的对话历史和活动历史和当前状态。

多应用可连接查看并操作同一工作流会话。

#### 工作流智能体

工作流智能体负责按工作流计划进行调度，传递用户指令和关联普通会话内容，不进行任务拆解、任务执行和任务决策，工作流智能体可执行工作流计划中明确写出的条件分支（如「审查不通过则打回修改」），但不创造计划之外的步骤、不自主变更目标，未在工作流计划和用户指令中指定的事项交由用户决定。

#### 工作流驱动

工作流智能体在调度动作结束后进入空闲状态，当关联普通会话状态从工作中变为空闲且非取消原因时，系统自动以用户消息向工作流会话注入一段提示词，触发工作流智能体进入工作状态，进行下一阶段调度。

用户可随时向工作流会话输入指令来调整工作流调度、恢复已取消或执行异常的工作流。

需要人类判断时（如通知人类审查），工作流智能体在工作流会话输出结论并回到空闲状态等待，用户审查完毕后，向工作流会话输入指令来继续推进工作流。

#### 工作流计划

工作流计划通过自然语言描述，支持指定机器和 agent，支持指定工作目录，支持使用 worktree 方式，支持编码-审查循环，支持人类审查等等。以下是一段示例

> 使用 xxx 远程机器的 codex 实现功能并提交推送分支，然后使用本机的 claude code 拉取代码并审查，并将审查意见给到 xxx 远程机器的 codex 进行修改，直至审查通过，然后通知人类审查。人类审查通过后，最终由本机 kimi code 操控浏览器创建 PR

用户可提前保存工作流计划，可用于快速发起工作流会话。

### 改动审查

用户可在应用内部查看当前普通会话的文件改动，并进行审查
- 支持以文件树方式浏览改动文件
- 支持 inline 方式查看文件改动
- 支持引用文件或代码块
  - 文件引用为复制文件路径到输入框
  - 代码块引用为复制代码块内容到输入框

### 工作目录浏览

用户可在应用内部浏览当前普通会话工作目录
- 支持以文件树方式浏览目录
- 支持查看文本文件内容

### 技能管理

集中管理用户常用技能，可对不同机器的不同 agent 安装、更新或卸载指定技能。
- 技能格式：包括名称和一段提示词（可以是仓库 / 资源 URL，也可以是下载与安装的方法说明）
- 技能安装、更新或卸载：通过创建一个普通会话，工作目录为系统临时目录，系统拼接提示词作为用户消息往该会话发送，由 agent 根据提示词进行安装、更新或卸载，用户可随时进入该会话干预调整

### 快捷指令

快捷指令是提前保存的一段常用提示词，用于快速发送而无需用户打字或说话。
- 指令格式：包括名称和一段提示词
- 指令使用：通过 UI 按钮点击，往普通或工作流会话中发送提前保存的提示词作为用户输入

### 机器管理

用户可在产品内进行机器管理
- 查看机器列表
- 重新发现机器上的 agents
- 查看机器上 agent 列表
- 查看 agent 状态：可用或不可用
- 可手动触发 agent 重启

## 应用 UI 设计

### 登录页面

应用打开后，正在建立连接过程中，整个页面展示转圈。

应用打开后，当无法成功连接 Server 时，则会进入登录页面，其内容居中展示
- 错误提示：当连接失败时，展示错误信息。若本地无连接信息则不展示
- Server 地址输入框：桌面应用有而 Web 应用无此框
- 认证 token 输入框
- 进入按钮：点击并连接成功后进入主页面

### 主页面

应用主页面布局采用左、中、右三块面板，面板宽度均可拖拽，不限制最大宽度，最小宽度以保证可拖拽回为准。

左侧面板包含
- 会话列表视图
- 设置入口：位于左侧面板左下角，点击打开设置浮窗

中间面板包括
- 新建会话视图
- 会话交互视图

右侧面板默认折叠，需要点击中间面板悬浮按钮才能展开
- 工作目录（仅普通会话展示）
- 改动审查（仅普通会话展示）
- 会话详情：会话元信息（包含所属机器与 agent、工作目录、创建时间等尽可能多的信息）
- 会话活动
- 会话计划（仅普通会话展示）：展示 agent 计划，若无则空白
- 终端（仅普通会话展示）：可创建多个终端，可关闭终端，可执行 shell 命令并查看输出

#### 会话列表视图

会话列表视图位于左侧面板，包含新建会话入口、会话列表
- 顶部栏
  - “会话列表”标题：左对齐
  - 新建会话按钮：采用「+」，右对齐，点击进入新建会话视图
- 会话列表包含普通会话与工作流会话，统一按最近活跃排序
- 工作流会话挂载若干关联普通会话，默认折叠，可展开查看；展开后关联普通会话按其自身最近活跃排序（不影响工作流会话在列表中的位置）
- 每条显示会话标题和会话状态，状态通过转圈（右对齐）表示工作中
- 会话列表默认仅展示首页会话，滚动至底部或顶部时自动加载下一页或上一页
- 右键点击会话列表项弹出菜单
  - 重命名：行内修改标题，按 Enter 保存，按 ESC 或输入框失焦则取消
  - 删除：弹窗确认
- 左键点击会话列表项，中间面板进入会话交互视图

#### 新建会话视图

新建会话视图位于中间面板，居中展示
- 顶部为模式切换：普通 / 工作流
- 普通模式
  - 若无连接机器，则提示用户“请运行 amux-daemon 程序将机器连接至服务器”
  - 若有连接机器，则展示
    - 机器：采用选项按钮组
    - 智能体：采用选项按钮组
      - 若未选中机器，展示“请选择机器”
      - 若选中机器，展示机器上发现的 agents，不可用的 agent 置灰不可点击
    - 工作目录输入框：输入框点击后，弹出上拉框展示从最近目录中选择，用户手动输入时，取消上拉框，自动弹出下拉框展示前缀匹配的目录项可供选择，当输入框失焦后取消上下拉框
    - worktree 开关
    - 创建会话按钮：默认置灰不可点击，当已选择机器、已选择可用 agent、工作目录非空后才可点击
- 工作流模式
  - 若工作流智能体未配置，则报错并引导用户进入设置页面-内置智能体设置
  - 若工作流智能体已配置，则视图为
    - 工作计划输入框：用户直接输入，也可从上拉框中选择提前保存的计划
    - 创建会话按钮：默认置灰不可点击，当工作计划已输入或已选择后才可点击
- 点击创建会话按钮后，跳转至会话交互视图

进入新建会话视图时，收起右侧面板。新建会话视图应记住当前所选模式，以及表单输入内容，创建会话成功后清空表单。

#### 会话交互视图

会话交互视图位于中间面板
- 顶部智能体名称和可用状态：左上方标注智能体名称（`<agent>@机器` 或工作流智能体）和智能体状态
- 对话历史
  - 类似 IM 应用展示用户消息与智能体输出的消息气泡，消息气泡包含时间和消息内容，消息内容按 markdown 格式进行渲染
  - 可滚动查看对话历史，滚动至底部或顶部时自动加载下一页或上一页
  - 进入时自动滚动到最底部
- 实时活动——展示正在进行的活动（如无则不展示），格式为 `<活动类型> <活动内容>`，宽度自适应 + 超长省略
- 快捷指令栏——以按钮形式展示用户设定的快捷指令
- 输入区
  - 多行输入框，可拖拽高度，Enter 发送，Shift + Enter 换行
  - 可拖拽文件和图片，可粘贴图片
  - 输入 `/` 时根据前缀匹配斜杠命令，弹出上拉框供用户选择
  - 输入框右侧为发送和取消按钮
- 会话选项——位于输入框下方，根据选项类型使用下拉框、开关等组件，宽度自适应 + 超长省略
- 悬浮按钮——悬浮于右侧上方，竖向排列，点击展开对应的右侧面板

#### 工作目录视图

工作目录视图位于右侧面板
- 顶部为工具栏：折叠/展开文件树按钮（左对齐）和折叠/展开内容区域按钮（右对齐）
- 左侧为文件树区域，整个区域可展开/折叠
- 右侧为文件内容区域，当选中文本文件时展示其内容，可滚动查看，整个区域可展开/折叠

#### 改动审查视图

改动审查视图位于右侧面板
- 顶部为工具栏：折叠/展开文件树按钮（左对齐）和折叠/展开 diff 区域按钮（右对齐）
- 左侧为文件树区域，仅包含改动文件列表，整个区域可展开/折叠
  - 按目录层级以树形展示改动文件，仅包含改动文件的目录出现在树中，默认全部展开，每个目录节点可单独折叠/展开
  - 不含改动文件的中间目录与其唯一子目录合并为一个节点展示，合并节点只能整体折叠/展开
  ```
  > src
    > catalog
      > helper
        query.rs
      schema.rs
    > storage/s3
      > parquet.rs
  ```
  - 点击文件时，右侧自动滚动到对应 diff 区域
- 右侧以 inline 模式查看文件改动，可折叠全部 diff 仅显示文件名

#### 会话活动视图

会话活动视图位于右侧面板
- 活动条目格式：`<活动类型> <活动内容>`（宽度自适应 + 超长省略） + 时间（`YYYY-MM-DD HH:mm:ss`），可展开查看详情
- 可滚动查看（滚动至底部或顶部时自动加载下一页或上一页），进入时默认滚动到底部

### 设置页面

设置页面经主页面左侧面板底部的设置入口打开浮窗，浮窗以半透明遮罩盖在主界面之上，内部为分类导航侧边栏 + 右侧设置内容（类似系统设置），点遮罩或关闭按钮收起。

#### 连接设置

配置 Server 连接信息，包括
- Server 地址输入框（Web 应用无此框）
- 认证 token 输入框
- 保存按钮：默认置灰不可点击，当任意一项配置修改时才可点击，点击后弹出通知显示保存成功或失败

#### 机器管理设置

布局采用纵向堆叠的卡片式，每台机器一张卡片，卡片内有：
- 机器头：名称 + 「重新发现」按钮
- 多行机器信息
- 每个 agent 一行：agent 名称，agent 状态，重启按钮

机器重新发现按钮和 agent 重启按钮点击后需弹窗确认。

#### 内置智能体设置

配置大模型供应商连接，布局包括
- API 格式单选框：chat_completions / responses / messages
- Base URL 输入框
- API Key 输入框
- 模型名称输入框
- 推理级别输入框
- 保存按钮：默认置灰不可点击，当任意一项配置修改时才可点击，点击后弹出通知显示保存成功或失败

#### 快捷指令设置

布局采用纵向堆叠的卡片式，每个指令一张卡片，卡片内有：
- 指令名称
- 指令内容，过长则截断展示
- 编辑按钮，点击后弹窗表单输入框
- 删除按钮，点击后弹窗确认

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。

#### 技能管理设置

布局采用纵向堆叠的卡片式，每个技能一张卡片，卡片内有：
- 技能名称
- 技能描述，过长则截断展示
- 安装/更新/卸载三个按钮，点击后弹窗，可选择指定机器和指定 agent
- 编辑按钮，点击后弹窗表单输入框
- 删除按钮，点击后弹窗确认

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。

#### 工作流计划设置

布局采用纵向堆叠的卡片式，每个计划一张卡片，卡片内有：
- 计划名称
- 计划内容，过长则截断展示
- 编辑按钮，点击后弹窗表单输入框
- 删除按钮，点击后弹窗确认

卡片区右上方是 「+」按钮，点击后需要弹出表单输入框。
